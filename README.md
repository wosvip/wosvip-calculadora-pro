# WOSVIP Calculadora PRO

Calculadora avançada para navegador, criada com HTML, CSS e JavaScript puro.

## Recursos

- Calculadora científica com funções trigonométricas, logaritmos, raiz, potência e porcentagem
- Histórico persistente salvo no próprio navegador
- Juros simples, juros compostos e parcelas de financiamento
- Conversões de comprimento, massa, área, volume, velocidade e temperatura
- Gráficos de funções matemáticas em canvas
- Tema claro/escuro e layout responsivo para computador e celular

## Como abrir

Abra o arquivo `index.html` no navegador ou acesse a versão publicada pelo GitHub Pages.

## Tecnologias

HTML5, CSS3 e JavaScript, sem dependências externas.
